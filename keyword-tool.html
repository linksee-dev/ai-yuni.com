Yuni Keyword Research

Yuni Keyword Research is a keyword research tool built and used by Yuni, an independent developer. It looks up how many people search Google for a keyword each month, so Yuni can decide which topics and pages to build for Yuni's own websites.

What the app does

  • Takes a list of keywords (for example "text to song" or "lyric to song").
  • Calls the Google Ads API Keyword Planner (GenerateKeywordHistoricalMetrics) to get the average monthly search volume, the search volume for each of the last 12 months, competition level and top-of-page bid ranges.
  • Saves the numbers into Yuni's local keyword research notes (an Obsidian vault on Yuni's own computer).

Google data it uses

The app signs in with Google OAuth and requests one scope: https://www.googleapis.com/auth/adwords. It only reads keyword planning metrics. It never creates, edits or deletes campaigns, ads, budgets, billing settings or any other data in a Google Ads account, and it does not access Gmail, Drive, contacts or any other Google service.

Who can use it

The app is not a public service and has no sign-up. It runs as a command-line script on Yuni's computer and is used only with Yuni's own Google Ads manager account. There is no login page; this page is the app's home page.

What it does not do

The app does not generate, edit or store images or video, does not process personal data about other people, and does not sell or share any data.
